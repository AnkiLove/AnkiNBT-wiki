# 快速开始

先确认版本，再把对应的 jar 放进 `mods` 文件夹。进入游戏后，手持物品或在背包里悬停物品，按 `N` 打开 AnkiNBT。

## 选择版本

| 加载器 | Minecraft | Java |
|---|---|---|
| Fabric | 1.21 到 1.21.11，26.1 到 26.1.2 | 1.21 系列用 21，26.1 系列用 25 |
| NeoForge | 1.21 到 1.21.11，26.1 到 26.1.2 | 1.21 系列用 21，26.1 系列用 25 |

Fabric 版本需要同时安装 Fabric API。

## 打开编辑器

### 主手物品

1. 在主手持有一个物品。
2. 按 `N`。
3. 编辑器会打开并显示该物品。

### 背包悬停

1. 打开背包或容器界面。
2. 将鼠标悬停在想要编辑的物品上。
3. 按 `N`。
4. 编辑器会打开并显示悬停的物品。

没有持有或悬停任何物品时按 `N`，会提示没有可编辑的物品。

## 编辑模式

| 模式 | 适合 | 说明 |
|---|---|---|
| 简易模式 | 常规编辑 | 名称、描述、附魔、属性修饰、外观、药水效果等可视化编辑。 |
| 高级模式 | 精确修改 | 直接查看、搜索和修改 NBT 节点。 |

[简易模式](simple-mode.md){ .md-button }
[高级模式](advanced-mode.md){ .md-button }

## 保存与关闭

- 按 `Ctrl+S` 保存修改到物品。
- 保存功能仅在创造模式下可用。
- 按 `Esc` 关闭编辑器。
- 如果有未保存修改，会出现确认提示。

## 配置文件

配置文件位于 `.minecraft/config/ankinbt.json`。常用选项包括打开按键、默认模式、界面透明度、NBT 导出目录和关闭确认。
