# AnkiNBT 1.2.4 更新记录

1.2.4 是一次面向稳定性和可用性的版本。重点是补齐 26.1 系列支持，完善编辑器交互，并把文档迁移到独立的 AnkiNBT-wiki 项目。

## 新增和完善

### 版本支持

- 新增 Fabric 26.1、26.1.1、26.1.2 构建。
- 新增 NeoForge 26.1、26.1.1、26.1.2 构建。
- 1.21 系列继续使用 Java 21。
- 26.1 系列使用 Java 25。

### 文本编辑

- 名称和 Lore 编辑支持 `Ctrl+A` 全选。
- 支持方向键移动光标。
- 支持按住 `Shift` 选择文本。
- 支持鼠标点击定位、拖动选择和多行拖选。
- 支持给选中的文本插入颜色代码或格式代码。
- 颜色代码按 Minecraft `&` 格式处理，例如 `&c`、`&b`、`&l`、`&r`。

### 简易模式

- 基础属性、附魔、Lore、属性修饰、外观、药水和工具分类更完整。
- 附魔和属性修饰使用本地化名称，中文环境显示中文名并保留命名空间。
- 已添加的附魔和属性修饰支持单项 `X` 删除。
- 属性修饰增加说明，可在配置中开关。
- 主题色覆盖范围扩大到主要按钮、选择状态、边框和子编辑器。

### 药水编辑

- 药水类物品进入专门的药水编辑布局。
- 支持普通药水、喷溅药水、滞留药水和药箭。
- 支持基础药水选择。
- 支持自定义药水颜色。
- 支持多选添加药水效果。
- 每个效果可以单独设置时长、等级、环境、粒子和图标。
- 已选效果列表支持选择和滚动。

### 高级模式

- NBT 树支持搜索、展开折叠、添加、删除和类型校验。
- 编辑框补齐基础文本编辑能力。
- 搜索框在 1.21.9 到 1.21.11 和 26.1 系列的输入焦点问题已修复。

### 物品选择器和村民交易

- 物品选择器支持按名称和命名空间搜索。
- 村民交易编辑器的物品选择也支持搜索。
- 可编辑买入物品、第二买入物品、卖出物品、数量、最大交易次数、经验和价格倍率。
- 支持编辑现有村民，也支持写入村民刷怪蛋。

### NBT 文件

- 导入和导出支持分类、别名和自定义目录。
- 修复部分入口打开 NBT 文件时弹出两个外部选择窗口的问题。

## 修复

- 修复 NeoForge 26.1、26.1.1、26.1.2 启动时的模块导出冲突。
- 26.x 构建不再把 Minecraft 自身的 `net.minecraft` 包打进模组 JAR。
- 修复多个版本中编辑器、物品选择器和搜索框鼠标点击后无法输入的问题。
- 修复部分中文文本缺失、界面元素主题色不同步的问题。

## 文档

- 文档站迁移到独立仓库 `AnkiNBT-wiki`。
- 文档首页改为快速开始。
- 新增功能总览。
- 右上角 GitHub 链接指向主项目 `AnkiLove/AnkiNBT`。

## 验证

- 已在本地重新执行全部 30 个版本的 clean build。
- 构建结果：30 成功，0 失败。
- 已检查 26.x 修复 JAR 中不再包含 `net/minecraft` 路径。
