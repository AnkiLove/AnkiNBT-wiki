# 快捷键

## 全局快捷键

在游戏中随时可用：

| 快捷键 | 功能 |
|--------|------|
| `N` | 打开编辑器编辑手持物品（可在 控制 > AnkiNBT 中自定义） |
| `N`（背包界面） | 打开编辑器编辑悬停物品 |
| 实体/村民编辑键 | 看向实体或手持村民刷怪蛋时打开实体/村民编辑器，按键可在配置里调整 |
| 配置菜单键 | 打开 AnkiNBT 配置菜单，按键可在配置里调整 |

## 编辑器快捷键（两种模式通用）

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+S` | 保存修改到物品（仅创造模式） |
| `Esc` | 关闭编辑器（有未保存修改时弹出确认框） |
| `Ctrl+A` | 在文本编辑框中全选 |
| 方向键 | 在文本编辑框中移动光标 |
| `Shift` + 方向键 | 在文本编辑框中选择文字 |
| 鼠标拖动 | 在多行文本编辑器中拖选文字 |

## 高级模式快捷键

| 快捷键 | 功能 |
|--------|------|
| `上` / `下` 方向键 | 在树节点间导航 |
| `E` | 展开或折叠选中节点 |
| `Enter` | 编辑选中节点的值 |
| `Delete` | 删除选中节点 |
| 双击 | 编辑值（叶节点）或展开/折叠（容器节点） |

## 自定义打开按键

默认打开编辑器的按键为 `N`。如需修改：

1. 打开 Minecraft **选项** > **控制** > **按键绑定**。
2. 找到 **AnkiNBT** 分类。
3. 点击 **打开编辑器** 然后按下你想要的按键。
4. 新的按键绑定会自动保存。
