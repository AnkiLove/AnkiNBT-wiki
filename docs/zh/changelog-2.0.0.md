# AnkiNBT 2.0.0 更新记录

2.0.0 是 AnkiNBT 的重大正式版本，核心是对界面信息结构、编辑流程和操作方式进行系统性重做。本次正式版同时替换较早的 2.0.0 构建，补齐 Minecraft 1.21，并完成 Fabric 与 NeoForge 全版本真实客户端验证。

## 编辑器重制

- 重制物品编辑器的基础属性、附魔、Lore、属性修饰、外观、药水和工具页。
- 新增刷怪蛋实体与真实实体编辑，支持名称、生命值、常用状态、撤销和服务端回读。
- 重制村民交易编辑器，支持新增、复制、移动、删除、撤销、两项买入、卖出和全部交易参数。
- 支持村民职业、等级、类型与真实报价保存。
- 新增独立界面宽度、高度、缩放、实时预览和窗口重建。

## 显示与输入

- 更新游戏内 AnkiNBT 标识。
- 使用 Mynaui 位图图标，修复私用区字符显示为方格的问题。
- 修复兼容方法返回 `void` 时重复回退绘制图标的问题。
- 完善中文输入法、IME 焦点、鼠标选择和文本快捷键。

## 跨版本修复

- 修复附魔注册表重复 ID，确保 `minecraft:lunge` 最多出现一次。
- 修复低版本 Fabric 实体和村民交易编辑器的裁剪状态泄漏与背景闪烁。
- 适配 Fabric 1.21/1.21.1 的旧耐火 `Unit` 组件。
- 适配 Fabric 1.21.5/1.21.6 的不可破坏 `Unit` 组件。
- 修复跨版本 Holder、物品组件、实体标签、村民报价和 MerchantOffer 序列化差异。

## 发布范围

- Minecraft 1.21 到 1.21.11。
- Minecraft 26.1、26.1.1、26.1.2、26.2。
- Fabric 与 NeoForge，共 32 个独立 JAR。
- 1.21 系列使用 Java 21，26.x 系列使用 Java 25。
- Fabric 版本需要对应版本的 Fabric API。

## 验证结果

- 64/64 个加载器/版本/语言组合通过。
- 3648/3648 项物品、实体、交易和显示检查通过。
- 测试环境为独占全屏、GUI 缩放 4、中文与英文。
- 1984 张最终截图，运行时日志问题为 0。
- QA 自动化代码不会打入发布 JAR。
