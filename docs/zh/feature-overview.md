# 功能总览

AnkiNBT 1.2.4 重点补齐了物品编辑、药水编辑、村民交易、文本编辑和跨版本兼容。这个页面按实际使用场景整理功能，适合第一次安装后快速判断能做什么。

## 两种编辑模式

| 模式 | 适合谁 | 能做什么 |
|---|---|---|
| 简易模式 | 不想直接写 NBT 的玩家 | 用分类面板编辑名称、数量、耐久、附魔、Lore、属性修饰、药水效果和外观。 |
| 高级模式 | 需要精确改数据的作者 | 直接查看和编辑 NBT 树，支持搜索、添加、删除、展开折叠和类型校验。 |

两种模式可以在编辑器顶部切换。修改不会立刻写回物品，确认无误后按 `Ctrl+S` 保存。

## 物品编辑

- 支持主手物品，也支持在背包或容器中悬停物品后打开编辑器。
- 基础属性可编辑名称、数量、耐久、最大耐久、最大堆叠、修复花费、无法破坏、防火和稀有度。
- 外观项可编辑自定义模型数据、附魔光效、隐藏提示框、染色颜色和物品名称颜色。
- 工具项可复制 NBT、复制 `/give` 指令、导入 NBT、导出 NBT 和重置到打开编辑器时的状态。

## Lore 和文本编辑

1.2.4 的文本编辑器更接近常规输入框：

- 支持 `Ctrl+A` 全选。
- 支持方向键移动光标。
- 支持按住 `Shift` 选择文本。
- 支持鼠标点击定位光标，拖动选择多行文本。
- 选中文本后可以插入颜色代码或格式代码。
- 支持 `&` 颜色代码，例如 `&c` 红色、`&b` 青色、`&l` 粗体、`&r` 重置。
- Lore 多行编辑支持上下移动、删除和逐行调整。

## 附魔

- 附魔列表显示本地化名称，中文环境显示中文名并保留命名空间，英文环境显示英文。
- 添加附魔时可以搜索中文名、英文名或命名空间。
- 已添加的附魔可以单独修改等级，也可以点 `X` 删除。
- 支持一键清除全部附魔。

## 属性修饰

- 属性修饰列表已补齐中文显示和说明。
- 支持攻击伤害、攻击速度、护甲、护甲韧性、最大生命、移动速度、击退抗性、幸运值等属性。
- 支持三种运算方式：增加、基础乘法、总乘法。
- 支持选择生效槽位：任意、主手、副手、头部、胸甲、腿部、脚部。
- 已添加的属性修饰可以点 `X` 删除。
- 属性说明可在配置中开关，默认关闭，适合只想要干净列表的用户。

## 药水效果

药水类物品会显示专门的药水编辑区：

- 自动识别普通药水、喷溅药水、滞留药水和药箭。
- 可选择基础药水类型。
- 可设置自定义药水颜色。
- 可多选添加药水效果。
- 每个效果都可以单独设置时长、等级、环境、粒子和图标。
- 已添加效果列表可以滚动选择，选中后编辑该效果的参数。
- 支持清除全部自定义效果。

## 物品选择器和村民交易

- 物品选择器支持按物品名称和命名空间搜索。
- 村民交易编辑器可编辑买入物品、第二买入物品、卖出物品、数量、最大交易次数、经验和价格倍率。
- 选择交易物品时同样可以搜索。
- 支持编辑现有村民，也支持通过村民刷怪蛋写入交易数据。

## 实体和配置

- 实体编辑器用于编辑看向的实体或可写入实体数据的物品。
- 配置菜单支持调整默认模式、界面透明度、主题色、属性说明、导出目录和按键。
- 主题色会同步到主要按钮、选中项、边框和子界面。

## NBT 导入导出

- 导出文件默认保存在 `.minecraft/ankinbt-config/save-nbt/`。
- 支持按分类保存，也可以给文件设置别名。
- 导入界面会显示文件名、别名、大小和修改时间。
- 1.2.4 修复了部分页面打开 NBT 文件时重复弹出外部选择窗口的问题。

## 兼容范围

1.2.4 覆盖 Fabric 和 NeoForge：

- Minecraft 1.21 到 1.21.11
- Minecraft 26.1、26.1.1、26.1.2

1.21 系列使用 Java 21，26.1 系列使用 Java 25。Fabric 版本需要 Fabric API。
