# 简易模式

简易模式是一个可视化编辑器，专为不需要了解 NBT 知识的用户设计。2.0.0 使用顶部分类页签和可滚动属性面板，并可独立调整界面宽度、高度和整体缩放。

---

## 界面布局

- **顶部页签** — 分类导航（基础属性、药水、附魔、描述、属性修饰、外观、工具）
- **内容面板** — 所选分类的属性列表
- **顶部标题栏** — 物品名称、模式切换（简易/高级）、保存按钮
- **底部状态栏** — 状态消息

---

## 分类详解

### 基础属性

编辑物品的基本属性：

| 属性 | 说明 |
|------|------|
| **物品名称** | 自定义显示名称 |
| **数量** | 堆叠数量 |
| **耐久** | 当前耐久值 |
| **无法破坏** | 切换无法破坏标记 |
| **最大堆叠数** | 最大堆叠数量 |
| **修复花费** | 铁砧修复花费 |
| **防火** | 物品是否免受火焰/岩浆伤害 |
| **饱食度** | 食物饱食度（仅食物物品） |
| **饱和度** | 食物饱和度（仅食物物品） |
| **稀有度** | 物品稀有度等级（普通、稀有、珍贵、史诗） |

### 药水

当编辑对象是药水、喷溅药水、滞留药水或药箭时，简易模式会显示药水专用编辑区。

| 项目 | 说明 |
|------|------|
| **药水类型** | 在普通药水、喷溅药水、滞留药水和药箭之间切换 |
| **基础药水** | 选择原版基础药水效果 |
| **药水颜色** | 自定义药水瓶、药箭和提示文本使用的颜色 |
| **自定义效果** | 添加额外药水效果，并为每个效果独立设置参数 |

添加药水效果时可以多选。添加后，在右侧已选列表里选择某个效果，再分别设置：

- **时长**：效果持续时间，按游戏刻计算，20 tick 为 1 秒。
- **等级**：效果等级，从 0 开始，界面显示时通常等于实际等级减 1。
- **环境**：是否作为环境效果显示，通常用于更柔和的效果显示。
- **粒子**：是否显示药水粒子。
- **图标**：是否在状态效果栏显示图标。

!!! tip
    如果想做一瓶同时带多个效果的药水，先多选需要的效果，再逐个点选已添加列表中的项目调整参数。

### 附魔

管理物品附魔：

- **查看** 所有当前附魔及其等级
- **编辑** 附魔等级，点击等级值即可修改
- **添加** 新附魔，支持中文搜索
- **删除** 单个附魔，已添加列表右侧的 `X` 会删除对应项
- **一键清除** — 移除所有附魔

!!! info
    附魔列表包含所有原版附魔。中文环境显示中文名并保留命名空间，英文环境显示英文名。可在搜索框中输入中文、英文或命名空间进行筛选。

### 描述 (Lore)

编辑物品描述文本：

- **添加** 新的描述行
- **编辑** 现有行，点击即可修改
- **删除** 行，使用删除按钮
- **上下移动** 调整行顺序
- **颜色代码** — 使用 `&` 颜色代码（如 `&c` 红色、`&l` 粗体）
- **内置色板** — 色板选择器方便选色
- **格式化颜色代码** — 编辑确认后应用颜色与格式代码

### 属性修饰

添加和管理属性修饰符：

- **添加** 修饰符，支持中文搜索全部属性类型
- **属性类型** 包括：攻击伤害、攻击速度、护甲值、护甲韧性、最大生命值、移动速度、击退抗性、幸运值等
- **三种运算模式**：加法、基础乘法、总乘法
- **槽位选择**：选择修饰符生效的装备槽位（任意、主手、副手、头部、胸甲、腿部、脚部）
- **编辑** 现有修饰符的值
- **删除** 单个修饰符，已添加列表右侧的 `X` 会删除对应项
- **说明开关**：属性说明默认关闭，可在配置里打开

### 外观

自定义物品外观：

| 属性 | 说明 |
|------|------|
| **自定义模型数据** | 资源包自定义模型的整数值 |
| **附魔光效** | 强制开启/关闭附魔光效 |
| **隐藏提示框** | 完全隐藏物品提示框 |
| **染色颜色** | 设置皮革护甲染色颜色（RGB） |
| **物品名称颜色** | 修改显示名称颜色 |

### 工具

实用功能：

| 工具 | 说明 |
|------|------|
| **复制 NBT** | 将完整 NBT 数据复制到剪贴板 |
| **复制 /give 指令** | 生成并复制该物品的 `/give` 指令 |
| **重置物品** | 还原所有修改至原始状态 |
| **导出 NBT** | 将 NBT 数据保存为 `.nbt` 文件（可选分类和别名） |
| **导入 NBT** | 从之前导出的 `.nbt` 文件加载数据 |

#### NBT 文件导入/导出

- 导出的文件默认保存在 `.minecraft/ankinbt-config/save-nbt/`（可配置）。
- 可将导出文件按**分类**（子文件夹）组织管理。
- 每次导出可设置**别名**（友好名称），方便识别。
- 导入界面会列出所有可用的 `.nbt` 文件，显示别名、大小和修改日期。

### 村民交易和物品选择

村民交易编辑器不在物品简易模式的左侧分类里，但属于同一套可视化编辑体验。

- 看向村民或手持村民刷怪蛋时，可以打开村民交易编辑器。
- 支持新增、复制、移动、删除、切换和撤销交易。
- 支持买入物品、第二买入物品、卖出物品、数量、最大交易次数、经验、价格倍率、需求和特殊价格。
- 支持编辑村民职业、等级、类型并保存真实报价。
- 选择交易物品时会打开物品选择器，可按名称或命名空间搜索。
- 可通过主手物品快速填充交易物品。

---

## 使用技巧

- 点击任何可编辑字段即可修改其值。
- 修改不会立即生效，需要按 `Ctrl+S` 保存（仅限创造模式）。
- 可随时通过顶部切换按钮切换到高级模式。
- 文本编辑框支持 `Ctrl+A`、方向键、`Shift` 选择和鼠标拖选；选中文本后再点色板，可把颜色代码插入到选中内容上。
