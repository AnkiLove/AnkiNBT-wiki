```markdown
A modern client-side Minecraft NBT editor for item, entity and villager-trade workflows. Supports Fabric and NeoForge, covering Minecraft 1.21 through 1.21.11, plus 26.1, 26.1.1 and 26.1.2.

一个简单现代化的 Minecraft 客户端 NBT 编辑器，支持物品、实体和村民交易编辑。支持 Fabric 与 NeoForge，覆盖 Minecraft 1.21 到 1.21.11，以及 26.1、26.1.1、26.1.2。

## Features / 功能

- Simple Mode for visual item editing
  简易模式，可视化编辑常用物品数据
- Advanced Mode for full NBT tree editing
  高级模式，直接查看和修改完整 NBT 树
- Main-hand and inventory-hover item editing
  支持主手物品和背包悬停物品编辑
- Creative Mode saving, view-only behavior outside Creative Mode
  创造模式可保存，非创造模式可查看
- Item name, count, durability, max stack size, repair cost, rarity, fire resistance and unbreakable fields
  支持名称、数量、耐久、最大堆叠、修复花费、稀有度、防火和无法破坏等基础属性
- Enchantment editor with localized names, searchable list, level editing and per-row removal
  附魔编辑器支持本地化名称、搜索、等级修改和单项删除
- Lore editor with multi-line editing, `Ctrl+A`, cursor movement, `Shift` selection, mouse drag selection and color codes
  Lore 编辑器支持多行编辑、`Ctrl+A`、光标移动、`Shift` 选择、鼠标拖选和颜色代码
- Attribute modifier editor with translated names, optional notes, operation and slot selection
  属性修饰编辑器支持中文名、可选说明、运算方式和槽位选择
- Potion editor with base potion, custom color, multi-select effects and per-effect duration, amplifier, particles and icon options
  药水编辑器支持基础药水、自定义颜色、多选效果，以及每个效果独立设置时长、等级、粒子和图标
- Villager trade editor with searchable item picker, buy/sell items, max uses, XP and price multiplier
  村民交易编辑器支持可搜索物品选择、买入/卖出物品、最大交易次数、经验和价格倍率
- NBT import/export with categories, aliases and configurable save path
  NBT 导入导出支持分类、别名和自定义保存路径
- Configurable key binds, UI opacity, theme color and attribute notes
  支持自定义按键、界面透明度、主题色和属性说明开关

## Installation / 安装

1. Install the matching Fabric or NeoForge version for your Minecraft version.
   安装与你的 Minecraft 版本对应的 Fabric 或 NeoForge。
2. Fabric users also need Fabric API.
   Fabric 用户需要同时安装 Fabric API。
3. Download the matching AnkiNBT jar. Match loader first, then the Minecraft version after `mc`.
   下载对应的 AnkiNBT jar。先匹配加载器，再匹配文件名里 `mc` 后面的 Minecraft 版本。
4. Put the jar into `.minecraft/mods/`.
   将 jar 放入 `.minecraft/mods/`。
5. Launch the game.
   启动游戏。

## Usage / 使用

- Hold an item and press `N` to edit it.
  手持物品按 `N` 编辑。
- Open an inventory, hover an item and press `N` to edit the hovered item.
  打开背包后悬停物品并按 `N`，可以编辑悬停物品。
- Press `Ctrl+S` to save changes in Creative Mode.
  创造模式下按 `Ctrl+S` 保存。
- Press `Esc` to close the editor.
  按 `Esc` 关闭编辑器。

## Compatibility / 兼容

- Fabric: Minecraft 1.21 through 1.21.11, 26.1 through 26.1.2
- NeoForge: Minecraft 1.21 through 1.21.11, 26.1 through 26.1.2
- Java: Java 21 for the 1.21 line, Java 25 for the 26.1 line

More documentation:
https://ankilove.github.io/AnkiNBT-wiki/

Project:
https://github.com/AnkiLove/AnkiNBT
```
