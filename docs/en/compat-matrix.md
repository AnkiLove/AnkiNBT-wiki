# Compatibility Matrix

Current latest release: **2.0.0 updated build**

## NeoForge

| Minecraft | Status | Java |
|---|---|---|
| 1.21 through 1.21.11 | Supported | 21 |
| 26.1, 26.1.1, 26.1.2 and 26.2 | Supported | 25 |

## Fabric

| Minecraft | Status | Java |
|---|---|---|
| 1.21 through 1.21.11 | Supported, Fabric API required | 21 |
| 26.1, 26.1.1, 26.1.2 and 26.2 | Supported, Fabric API required | 25 |

## Release Files

| Loader | Example file |
|---|---|
| Fabric | `AnkiNBT-Fabric-mc26.2-2.0.0.jar` |
| NeoForge | `AnkiNBT-NeoForge-mc26.2-2.0.0.jar` |

When downloading, match the Minecraft version after `mc` first, then match the loader name.

## Java Selection

- 1.21 through 1.21.11: use Java 21.
- 26.1 through 26.2: use Java 25.

If your launcher supports per-instance Java settings, configure Java per Minecraft version so the 26.x line does not launch with Java 21 by mistake.

The updated 2.0.0 build was verified in 64 real-client combinations across Fabric, NeoForge, 16 Minecraft versions and both supported languages.
